Archive safety & lock-release flowลำดับความปลอดภัยตอน Archive และการปล่อยไฟล์ล็อก
What changesสิ่งที่เปลี่ยน

Sanitizes work slugs for Windows/Unix safety, preflights all target repos, creates central per-task work folders with git worktrees and task branches, guards dirty/untracked/ignored state, and cleanly detaches and archives completed folders.

ทำความสะอาด work slug ให้ปลอดภัยบน Windows/Unix ตรวจ preflight ทุก repo เป้าหมาย สร้างโฟลเดอร์งานกลางพร้อม git worktree และ task branch ตรวจสอบไฟล์แก้ค้าง/untracked/ignored และถอดพร้อม archive โฟลเดอร์งานที่จบแล้วอย่างเรียบร้อย

Whyเหตุผล

Isolates parallel multi-repo work in one folder per task and enables safe one-step archiving without breaking Git metadata, hitting Windows file locks, or losing uncommitted edits.

แยกงานหลาย repo ที่ทำขนานกันไว้ในโฟลเดอร์เดียวต่อ task และ archive ในขั้นตอนเดียวได้อย่างปลอดภัยโดยไม่ทำ Git metadata พัง ไม่ชนไฟล์ล็อกบน Windows และไม่ทำไฟล์แก้สูญหาย

What changesสิ่งที่เปลี่ยน

Centralized per-work state store (~/.devbench/state/works/<slug>.json) with per-work file locks, atomic tmp+rename writes, and phase checkpoints tracking work status, 1:1 Herdr workspace ID, target repos, worktree paths/branches, Herdr pane/hc IDs, and native AI session IDs + cwd; copies a frozen snapshot into the archive folder on completion.

ที่เก็บสถานะต่องานแบบรวมศูนย์ (~/.devbench/state/works/<slug>.json) พร้อม per-work file lock, atomic tmp+rename และ phase checkpoint เพื่อบันทึก work status, 1:1 Herdr workspace ID, repo เป้าหมาย, worktree paths/branches, Herdr pane/hc IDs และ native AI session IDs + cwd พร้อมคัดลอก frozen snapshot ลงโฟลเดอร์ archive เมื่อจบงาน

Whyเหตุผล

Gives the Dispatcher one instant central index of every active and archived work without folder scanning, avoids cross-work lock contention, stays outside every git worktree, and survives crashes cleanly.

ให้ Dispatcher มีดัชนีกลางของทุกงานที่กำลังทำและที่ archive แล้วทันทีโดยไม่ต้องสแกนโฟลเดอร์ ไม่แย่ง lock ข้ามงาน อยู่นอก git worktree โดยสมบูรณ์ และฟื้นตัวหลังขัดข้องได้สะอาด
