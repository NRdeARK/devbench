Recap from intent · before stateสรุปจากเจตนา · สถานะก่อนหน้า

Today the user manually opens Herdr panes or terminals, navigates into repositories, and runs raw commands to start each agent session.

ปัจจุบันผู้ใช้ต้องเปิด Herdr pane หรือเทอร์มินัลเอง เข้าไปยังแต่ละ repo และพิมพ์คำสั่งดิบเพื่อเปิดแต่ละ agent session

Issues on this problemปัญหาของเรื่องนี้
  • Placing an Owner or domain-worker session into a new workspace, tab, or split pane and creating isolated git worktrees for each repo takes repeated manual setup
  • Multi-repo tasks leave scattered branches with no single work folder or saved record of work status, Herdr pane IDs, and native AI session IDs to inspect or resume later
  • Checking which agent session finished or got stuck means inspecting terminals one by one
  • Orchestration logic, helper scripts, and personal machine config are mixed together across local skills instead of separated into a versioned plugin marketplace repo (with a config template) and a gitignored user config
  • การวาง Owner หรือ domain-worker session ใน workspace ใหม่, tab ใหม่ หรือ split pane พร้อมสร้าง git worktree แยกแต่ละ repo ต้องทำซ้ำด้วยมือทุกครั้ง
  • งานหลาย repo ทิ้ง branch กระจัดกระจาย ไม่มีโฟลเดอร์งานกลางหรือบันทึกสถานะงาน, Herdr pane ID และ native AI session ID สำหรับตรวจสอบหรือกลับมาทำต่อ
  • การเช็กว่า agent session ไหนเสร็จแล้วหรือติดปัญหาต้องไล่เปิดดูทีละเทอร์มินัล
  • ลอจิกการประสานงาน สคริปต์ช่วยงาน และ config ส่วนตัวของเครื่องปะปนกันใน local skill แทนที่จะแยกชัดเจนระหว่าง plugin marketplace repo (ที่มีไฟล์ config template) กับ user config ที่อยู่ใน `.gitignore`
Outcome success → use casesผลลัพธ์ที่สำเร็จ → ยูสเคส
O1

From one request to the Dispatcher, devbench creates a central multi-repo work folder with git worktrees, launches persistent Owner and optional domain-worker sessions in Herdr, tracks Herdr and AI session IDs/states for resumption, and archives the entire work folder cleanly when done.จากคำสั่งเดียวถึง Dispatcher devbench สร้างโฟลเดอร์งานกลางสำหรับหลาย repo พร้อม git worktree เปิด Owner และ domain-worker session แบบคงอยู่ใน Herdr ติดตาม Herdr และ AI session ID/สถานะเพื่อให้ resume ต่อได้ และ archive โฟลเดอร์งานทั้งหมดได้อย่างเรียบร้อยเมื่อจบงาน
